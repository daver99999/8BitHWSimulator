# Sinclair ZX80

`--machine zx80`. Z80A, 4K ROM (8332), 1K RAM (2 x 2114), discrete TTL: no ULA. The display is made by the CPU running the
display file with A15 high while IC14/IC15 force NOPs; /INT is wired to A6 and ends the HALT of every display line.

ROMs (not shipped): `roms/zx80/*.rom` (4096 bytes, the ZX80's) and `roms/ts1000/*.rom` (8192 bytes, the ZX81's). Choose with
`--option rom=zx80` or `rom=zx81`. With the 8K ROM pin 21 of IC2 is A12; the ZX81 ROM runs in FAST mode only.

The keyboard (option `keyboard=zx80|zx81`, or the Keyboard button in the control panel; independent of the ROM choice) is by default the ZX80's: the ZX81's matrix but its own shifted keys (SHIFT+1..4 NOT AND THEN TO, +5..8 cursors, +9 HOME, +0 RUBOUT, +NEWLINE EDIT, +Y U I O P is " $ ( ) *), from a scan of the keyboard. The ZX80 ROM is not the ZX81 ROM, so with the ZX81 ROM the keywords differ from the legends.

The netlist is `tools/zx80-netlist-src/` (built from the PDF with `tools/zx80-extract/`). The crystal is not simulated (the
machine drives IC20's amplifier) and C11 is a pulse made once per phi rising edge. The power supply, modulator, EAR/MIC and edge
connector are not modeled. Parts are placed from a scan of an Issue 3 board; the order inside resistor groups, and R19/R20/R24/R25, are guesses.
