# Timex Sinclair 1000 (ZX81), board Issue 3

`--machine ts1000`, or Timex > TS1000 in the controls.

**Status: reconstructed.** No schematic of this board was available. The netlist (`tools/ts1000-netlist-src/sheet01.py`)
is built from published descriptions of the ZX81 circuit; every guess is marked INFERRED. Refs are the Issue 3 ones
(IC1 ULA, IC2 ROM, IC3 Z80A, IC4 RAM, R35-R42 data pull-ups, R43-R47 keyboard pull-ups). The part placement is taken from a photo of an Issue 3 board (turned a quarter turn clockwise, edge connector at the bottom), good to a few mm; the references of the 470 ohm data and 1K address resistors are not read from the silkscreen.
That board has a Forth ROM, a switching regulator and a 32K RAM mod, none of which is modeled. Verify doubtful nets against a real board one at a time.

- ROM: put the 8K ZX81 ROM (`.rom`/`.bin`, 8192 bytes) in `roms/ts1000`. It is not shipped.
- The ULA is a functional model (clock, sync counters, NMI, keyboard/tape port, video fetch).
- Not modeled: power supply, modulator, tape circuits, RAM pack, loading programs.
- Keyboard: RUBOUT is the same as DELETE (Backspace on the PC).
